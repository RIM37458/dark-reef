# Agent Instructions

- Read `CONSTRAINTS.md` before writing code. Do not weaken it to make a change pass.
- Use Addy Osmani's Agent Skills as executable workflows, selected through `using-agent-skills`.
- New features follow `spec-driven-development` → `planning-and-task-breakdown` → `incremental-implementation` → `test-driven-development` → `code-review-and-quality`.
- Bug fixes follow `debugging-and-error-recovery` → `test-driven-development` → `code-review-and-quality`.
- Every code change follows `git-workflow-and-versioning`; use the smallest additional specialist skill that covers the task.
- Comments explain only non-obvious reasons. Do not preserve intermediate attempts in code or comments.
- Pull request descriptions state final behavior and decisions that are not evident from the diff. Do not mention abandoned or never-merged approaches.
