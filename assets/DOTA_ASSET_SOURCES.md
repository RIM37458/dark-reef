# Dota asset sources

- `dota-map-detailed-740.jpg`: Dota 7.40 detailed map distributed by the OpenDota web project.
- `dota-minimap-hero-sheet.png`: Dota minimap hero sheet extracted from Valve's `pak01_dir.vpk` by the `dota2-minimap-hero-sprites` project.
- `dota-minimap-heroes.css`: sprite coordinates from `dota2-minimap-hero-sprites`, adjusted only to load the colocated sheet.
- `hero-portraits/*.png`: Valve hero portraits fetched from the Steam static CDN URLs recorded in `hero-portraits/manifest.json`; bundled as offline visual references for local screen recognition.

Dota 2 images and names are property of Valve Corporation. These files are used by this unofficial local companion application and do not imply Valve endorsement.
